# 개발사 프론티어 안전 정책

METR Common Elements 목록을 시드로 하고, Vorp·AGORA·국내 공개 문서로 보강한다.

개발사가 공개한 **프론티어 안전 프레임워크**와 **윤리원칙·헌장**을 함께 수록하며, 문서종류는 모두 `개발사 정책`이다.

| 역할 | 출처 |
|------|------|
| 프론티어 안전 목록 | [METR Common Elements](https://metr.org/common-elements), [METR FSP](https://metr.org/fsp) |
| 버전·일자·추적 | [Vorp inventory](https://vorplabs.com/ai-regulatory-updates/frontier-ai-frameworks) |
| 기존 수집 이관 | AGORA Inflection Frontier Safety |
| 한국 개발사 | NAVER ASF 2.0, Kakao ASI, LG 책무성, Upstage·Samsung SDS·KT·NCSOFT 윤리원칙 등 |
| 병행 수집 | IAAE의 네이버·카카오·LG·SKT 윤리문서 (`개발사 정책`) |
| 설계 참고(비시드) | [UK AISI Emerging practices](https://www.aisi.gov.uk/research/emerging-practices-in-frontier-ai-safety-frameworks) |

문서종류: `개발사 정책`
